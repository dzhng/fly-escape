# Motion belongs to the body

A body step returns its events and one finalized trajectory together. Collision construction, intermediate event poses and replay sampling use the same timed knots. Sampling interpolates root and quaternion directly; it does not query or project onto food. Terminal motion retains its original tick fraction and holds the reached pose for the remainder.

Supported movement is a bounded numerical approximation. It checks authored food, including closed-volume containment, and refines contact samples without clearance offsets. A selected-food support query already supplies the full-hull upper root at a sample; its vertical difference measures that food’s sampled path error. Separate contact queries cover every neighboring food. Validation samples are not automatically retained as replay knots. An absent upper support sample does not authorize dropping from a still-touching pose: the departure experiment first advances the requested planar motion and heading, then requires separation before descent. Blocked or unresolved candidate movement retains a verified safe prefix, or the validated starting pose when the query budget is exhausted. Invalid starting contact and failed native queries remain errors. Holding a pose still advances simulation time and neural state. A separately safe turn must not repeatedly postpone a reachable object landing: the retained orientation may finish a verified descent even when the combined turn is declined. Successful object acquisition rests for the remainder of the tick, so leftover flight velocity cannot exhaust the supported-walking budget and discard the landing.

Under the finite-life reserve model, grounded taste can start a neural feeding bout; a timed round spends and gains nothing, so food only carries, tastes and slows a walking body. Feeding stops at the detected contact-loss prefix, bout limit or satiation; energy before and after that boundary is integrated separately. Contact-loss bracketing is numerical and does not prove absence of a very narrow missed gap between checks. Floor-grounded contact with food remains edible; airborne contact does not become feeding support.

The native reference hull remains the runtime owner. Candidate-hull request tests are comparison diagnostics. Query and knot limits bound work without guaranteeing that every authored request fits. Packed trajectory transport and the shared WASM sampler preserve the finalized body path in browser replay; the active specification owns remaining campaign, contact and performance acceptance. Wall contacts preserve approach timing, remove only blocked velocity components, and sweep the remaining sideways travel before recording the next bend.
