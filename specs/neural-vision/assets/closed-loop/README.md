# Production-body motion evidence

Lighting changes individual trajectories through the circuit, but these bounded panels resolve neither approach nor avoidance. Every left/right/forward distance and heading interval includes zero for both initial modes. This is not a basis for an attraction puzzle.

The probe retains the supplied production body configuration, uses normal Attempt startup and removes odor, food, wind, fans, exit cue and suction. Each mode has thirty paired seeds, one dark run and three lamp runs per seed. All attempts completed their full neural workload without boundary contact. The summaries use unadjusted seed-level intervals descriptively, not a selected behavioral winner or a puzzle acceptance gate.

[The summary](summary.json) links results through the co-located full walking/flying reports. The exact production input is retained here; the fixture and identity hashes in each report establish what actually ran. The native [probe](../../../../../crates/sim/examples/vision_motion_probe.rs) owns fixture construction and metrics. Its reference positions only measure the dark run; they do not enter its sensory or movement inputs.
