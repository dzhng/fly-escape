# 1. Audit and freeze candidate input maps

Question: which already-selected visual cells can receive eight spatial light channels while retaining actual paths through the exported circuit?

Write a bounded audit/export tool in `scripts/connectome`. Read the local MaleCNS v1.0 annotation Feather and current graph/manifest. Record source hashes, graph hash, cell type, superclass, side, assignedOlHex1/2, selected/source counts and retained directed paths to existing visual relays and motor readouts. Include the inherited AOTU inventory as a rejected eight-sector source. Query actual CSR edges, not the full source graph as a substitute for what ships. Exclude every `motor_readout_indices` equivalent set.

Candidate families are exactly Tm2 and Tm20. For each, require selected cells on both sides, finite assigned columns and at least one retained downstream path per populated sector. Audit the entire selected family, including cells rejected for missing coordinates or paths. No manual body list. Count all sectors and sides; show how selection differs from full source coverage.

Inspect the primary MaleCNS eyemap documentation for horizontal registration. If it does not provide calibrated azimuth, use an explicitly modeled coordinate projection: normalize assignedOlHex1 over the full annotated family on each eye, map that coordinate linearly across that eye's half-circle (left: 0 to -pi, right: 0 to +pi), and assign the nearest 45-degree bin, modulo eight. The axis choice, direction, mirroring and half-circle field of view are assumptions, never labeled observed retinotopy. Do not use soma xyz, body-ID sorting or FlyWire correspondences as angular coordinates. Save the exact equation and source ranges in the artifact before experiments; do not flip the registration to produce attraction.

For each candidate, output eight disjoint arrays of existing neuron indices with source body IDs in the audit, plus per-bin count normalization `min(nonzero bin counts)/bin_count`. This preserves the same total external current for equal-brightness basis stimuli, without increasing any per-neuron current above the global gain. Every bin must be nonempty and reachable; otherwise reject that candidate with an explicit reason. The mapping is resolved once; no annotation lookup or per-frame graph traversal.

The map data contract includes annotation SHA-256, graph SHA-256, family, registration statement, eight index arrays and normalization. Freeze both candidates as experiment inputs. The selected winner alone later enters the production manifest; graph bytes and original synaptic weights remain unchanged. Existing vision display groups eventually summarize the selected left/right cells; do not add eight extra trace groups or leave AOTU labels describing different cells.

Verification: reproducible map hashes; all indices/source identities present; exact type/soma side and finite columns; motor intersection empty; all eight sectors distinct/nonempty; actual retained path examples and counts; dose normalization equal across basis directions. Test identity errors, invalid index/duplicate membership, empty channel and corrupted normalization at the exporter/loader seams when materialized. No behavioral claim comes from this audit. Deliver a concise table and JSON, not a new web application. Internal file names and report formatting are delegated. Commit the audited frozen candidates and update the handoff before slice 2.
