# Firing-based steering produces spatial approach

Scratch only. At b77198b, replace the olfactory contribution to walking and flying turn with four times the right-minus-left firing fraction of the existing olfactory descending-neuron groups. Keep thrust, the flight-specific voltage contribution, neural dynamics, sensory input, noise and anatomy unchanged. Four was fixed from the preceding fixed-input response magnitudes before running these trials. No smoothing or source-binding change was applied.

The preserved probe runs both decoders through the existing moving Chamber owner, 30 seeds per source side/pathway with paired no-current controls: 480 runs, 100 ticks each, cold brains, settled fields, gain two, source initially one metre away. Root compared 2400 baseline values against the earlier cold-odor experiment: all matched exactly. Raw data, exact patch and source identity are included.

Each value compares stimulus with its own decoder's same-seed no-current control. Firing-based excitatory approach has descriptive 95% intervals [.7250,.7697] and [.4541,.4927] m. Inhibitory movement away has intervals [−.0566,−.0368] and [−.1025,−.0770] m. Directional turn contrasts agree on both mirrored sides. Endpoints remain away from walls, so the approach is not a wall stop. This supports spatial attraction and weaker repulsion in this controlled fixture, not real biological fidelity or complete game balance.

Source bindings in this experiment retain the production assignments, so the excitatory group is still fed the channel currently named repellent and the inhibitory group the channel named attractive. A production candidate must deliberately reverse those assignments to match the measured effects. Changing only the decoder would make object names misleading.

The no-current control also changes: average absolute turn rises from .0379 to .0714. That is a behavior change to evaluate in the full game, not a proven defect requiring a smoothing mechanism. Root retained one scale and no smoothing for the next test to avoid optimizing multiple variables at once. The agent suggested smoothing; it was not adopted.

Next proof: complete Attempt/Body runs with actual source bindings and both initial modes, then authored campaign trials. The laboratory's simpler walking integration does not by itself prove the full flying/landing/contact behavior. Numerical motor-oracle fixtures would intentionally diverge under this candidate; no reference test has yet been changed.
