# Watched stars unlock navigation

The regression runs real worker physics with four flies near the exit and twelve in another room. Computation can finish while playback is paused without awarding stars. Watching the fourth escape saves one star and enables the next level before the replay ends. The browser then rewinds, selects the next level and reloads to confirm progress remains saved.

Restoring disabled navigation makes the test fail on the enabled-level assertion; restoring the fix passes. The scoped independent code review found no actionable defects. Focused progress/campaign tests and type checking pass. The screenshots capture a real four-escape milestone and the selected second level.
