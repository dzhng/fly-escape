# Protocol-specific geosmin input evidence

[The 2019 single-sensillum study](https://elifesciences.org/articles/51040) provides electrical spike measurements, unlike a calcium fluorescence curve. Its [Figure2 source data](https://doi.org/10.7554/eLife.51040.009) contains genetic-background controls separately from odorant-binding-protein mutants. The extracted control rows and workbook checksum are in `control-responses.json`. Root inspected Figure2D to confirm the row-to-odor mapping and spikes/second axis.

At stimulus solution concentrations0.2µg/ml and20µg/ml, the six control responses average17 and80.6667 evoked spikes/second. Do not substitute the paper’s approximate prose value for the source-data mean. Methods subtract the preceding500ms unstimulated spike count from the500ms stimulated count, starting40ms after odor onset to allow transport. The plotted values are rates, not unconverted half-second counts. Diluents alone were not subtracted. The subjects were3–6-day-old female flies; the game’s connectome is male. These concentrations describe the stimulus preparation, not a measured airborne concentration at the antenna.

This supplies two evoked-response targets, not a full receptor transfer function, baseline firing rate, spike-time distribution or adaptation model. A different [2024 study](https://www.mdpi.com/1422-0067/25/13/7125) reports baseline activity and normalized dose-response fits, but mixing its protocol with the2019 evoked measurements would be an additional modeling assumption. Do not silently combine them into one measured curve.

The existing architecture explicitly treats LIF dt=1 as a model unit (CONTRACTS.md), with one neural step per0.1 game seconds. This is documented abstraction, not a newly discovered coding bug. A rate-in-Hz experiment needs an explicit local timebase and a measured check of realized receptor firing. Merely relabeling a step as a millisecond or increasing current does not calibrate the downstream dynamics. The previous DA2 current2 pulse approaches0.5 spikes/step and is not these source responses.

Next define an experiment-local encoding that reproduces the observed evoked rate under its stated timebase, with the encoding assumptions exposed. Preserve no-stimulus comparisons and measure realized input before interpreting downstream activity. Do not calibrate against avoidance or escape score. No runtime encoding has been adopted from these two data points.

## Experiment-local input fit

A fixed, bounded bisection selected currents using only DA2 receptor during-minus-before firing on seed0. It does not establish that the existing neural dynamics or game clock are physiologically timed. All48 retained DA2 receptors receive the same input; no current reaches a motor readout directly. No movement, field or escape output participates in fitting.

Root independently repeated all27 runs and matched all outputs except elapsed wall time. The agent batch took32.7seconds; the root rerun was slower under different machine load.

The model baseline is not fitted to a physiological baseline. A constant current fitted to a mean evoked response is a phenomenological input approximation; it does not reproduce spike timing, adaptation, a full concentration curve or an airborne plume. Both relay populations respond, but this bilateral experiment predicts no steering direction. The small readout changes cannot establish avoidance or its absence. The next discriminating observation is lateralized input at these frozen strengths, with realized receptor activity checked and with no body/decoder changes; chemical-field and physiological-clock claims remain unaccepted. Do not turn this fit into a strong-current game repeller.

## Walking-readout evidence to observe independently

[The DNa02 steering study](https://elifesciences.org/articles/102230) relates right-minus-left DNa02 activity to walking turns. Its Figure5 attractive stimulus activates most Orco-expressing sensory neurons optogenetically; its aversive stimulus activates thermosensory neurons. It does not establish that selective DA2 stimulation must produce a particular DNa02 response.

The current source annotations identify DNa02 right as10360 and left as523769. Both are retained, but neither belongs to the current olfactory turning readout. DNa01 left10442 and right10760 are also retained and absent from that readout. Observing these literature-motivated cells is justified independently of game scores; replacing the decoder solely because their output looks more useful is not. The existing unilateral DA2 test measures the current readout, so it cannot establish absence of a signal in these unobserved cells.
