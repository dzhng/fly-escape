# Global threefold odor emission

Eight completed sixteen-fly, ten-minute attempts compare global3× with the matching normal-emission controls in [scent-strength evidence](../scent-strength/README.md). Scaling includes authored odor sources and fixed/placed catalog objects. Physical objects, light, exit cue, airflow, neural dynamics and original doorway-only suction are unchanged. The candidate concentration encoding uses c/(c+0.55).

Global amplification does not reproduce the banana-only competitive advantage. Binary aggregate escapes are unchanged. Under concentration encoding, global3× yields8 empty versus7 banana escapes, compared with3 versus6 at normal emission. This small sample does not support adopting a global boost to improve placement control. It does not prove every layout would fail. Production emission remains unchanged; banana-only amplification was a diagnostic isolation, not an object-specific shipping rule.

Independent review confirms scaling and matching controls. At the same pose/time global scaling preserves relative contrast and winning side in this fixture, whose exit cue is null. Binary changes begin through the absolute detection floor (and numerical precision); concentration encoding also changes amplitude. Subsequent trajectories can diverge. This house has no active repellent emitters, although the implementation supports both odor channels; synthetic repellent and lamp sources extend validation to those branches. The earlier claim that inhibitory amplitude was an active experimental confound is corrected: only attractive gain changes here.

The resolved-source validation checks triple odor rates and unchanged non-odor rates, physical state and field configuration. Raw identities, complete reports and source snapshots are retained. Measurement caveats from the source comparison still apply; arrival counts and escapes are the main outcomes. No star threshold or production sensory parameter changed.
