# Retained rotating chart interval probe

**Bounded positive coverage, no motion adoption.** A face/vertex chart discovered
from the initial native query certifies the complete short turn, tilt and mixed
intervals against the sole authored apple. Its witness stays in the native hull
vertex cone and triangle domain, and every other apple triangle has a whole-interval
AABB exclusion or strict support-axis separation certificate. No sampled absence,
added clearance or small-excursion ownership shortcut is used.

[Results and budgets](retained-chart-interval-results.json) include explicit
unresolved prefixes at wider cone exits and the edge case's work limit. Sharing
sin/cos and midpoint geometry reduces duplicate work without changing coverage.
Twenty-run native certificate means are 0.28–0.54ms for short intervals and
24.5–35.9ms for unresolved wider cases. This is not campaign or browser acceptance.

Outward-rounded binary64 operations enclose quaternion/axis normalization and
Taylor sin/cos (degrees32/33, remainder5e-22 on the tested angle range). Geometry
means the exact rounded millimetre coordinates used by the query. The declared
axis-angle path has a binary64 angle; conversion from requested endpoint rotations
to that declared path is not certified. The analytic chart root differs from the
initial core sample by at most1.21e-12mm; this experiment does not preserve a
caller's root exactly. Diagnostic samples agree with core support within7.31e-12mm
and native slerp point positions within4.60e-15mm, which are observations, not proofs.

Independent numerical review found no false certificate for the finite fixtures.

rotating edge/face denominators are not tested. A certified chart handoff is the

Budgets count logical work and storage depth, not CPU instructions or wall time.
