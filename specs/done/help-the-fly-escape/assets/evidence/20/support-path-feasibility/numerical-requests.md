# Numerical trajectory baseline

The same six captured body requests and the narrow apple-edge turn complete a numerical support-knot sweep without query errors. Root positions interpolate linearly between core support samples; orientation uses the same stored endpoints and SLERP for support construction and diagnostic sampling. The original supplied start is retained. There is no clearance offset.

Seeding segments at no more than 0.05 mm planar travel and 0.01 radians rotation gives nine segments for the upright requests. Independent samples measure at most 0.01003 micrometres vertical root deviation and 0.00876 micrometres penetration. Halving the steps reduces these to 0.00275 and 0.00241 micrometres. Aligned walking needs eight seed segments and measures 0.00557 micrometres vertical deviation with no measured penetration. These values are below the provisional 3 micrometre trajectory budget; the small positive penetration remains explicitly reported. The unchanged query precision is 10 nm.

[Results](numerical-request-results.json) include the larger uniform sweep and seed/half-step comparison. Nine static support and contact samples per segment are diagnostic telemetry, not a continuous nonintersection proof. Reported elapsed time includes this dense validation, so it is not production cost. The endpoint/midpoint query count is an estimate for a prospective producer, not a measured implementation. Whole-segment hull excursion bounds travel only; it cannot establish contact ownership or rule out a gap.

This checkpoint supports trying a practical bounded numerical trajectory. It does not accept landing, feeding, walking off an edge, departure or revisiting; those lifecycle cases, adaptive budget behavior, shared replay transport, maximum close-view pixel error and 20-body WASM cost remain open. The single apple and prepared candidate are diagnostic fixtures, not immutable user choices. Runnable sources remain in `/tmp/fly-rotation-probe`.
