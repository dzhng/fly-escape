# Shared numerical replay integration

Body returns its finalized trajectory with events. The existing packed record carries timestamped position/orientation knots and support flags; FrameArchive retains the transferred buffers. A pure Rust sampler, exported by the existing WASM module, consumes only the selected tick on the main thread. It uses the same interpolation as body events and loads no brain or contact scene. Renderer endpoint interpolation is removed from game playback. Diagnostic integer-tick workbenches still read exact recorded endpoints.

The current packed layout stores all retained knots, including endpoints. Fixed-record worst-case bytes are reserved first; variable motion shares the128MiB cumulative quota. Both producer and archive reject overflow explicitly. This is a resource limit, not proof every6000-tick furnished attempt fits: actual retained counts and producer cost remain open. Two endpoint knots alone cost160bytes per fly-tick; free-motion coalescing and supported-path accuracy/cost are being measured. The wire layout is strict and replaced together; no compatibility reader or persistent save format is added.

Verification: eight core unit tests, seven record tests and three WASM-session tests pass, including curved interior samples, malformed offsets, exact terminal holds and explicit archive overflow with the pending chunk preserved. Twenty-one client tests/222assertions and TypeScript pass; the client interior-knot test fails when sampling is falsified to the endpoint. Native library/tests Clippy and both browser application builds pass. The actual [Worker transport](transport.json.gz) retains deterministic real-graph frames, buffer detachment, bounded hidden production and cancellation/restart behavior. The [browser playback](playback.json.gz) passes pause, seek,2×, replay, restart and shared sample time. This ordinary movement fixture does not prove curved-food visual accuracy.

A local Bun/WASM probe with twenty synthetic recorded trajectories measured mean sampler calls of0.0042ms for2knots,0.0030ms for6 and0.0162ms for129 across1000calls after10warmups. The maximum batch input was206,484bytes. This measures stateless sampling/copy cost only, not browser FPS or neural/contact construction. No full archive is mirrored into WASM.

Open: stronger wind/contact coverage, chosen native hull and actual maximum-close error, twenty-brain food duty/cost, complete archive consumption, furnished food placement and production visual acceptance.
