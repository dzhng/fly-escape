# Retained motion and numerical workload

Free and floor straight movement retained six knots for five collision-query substeps. Core coalescing reduces these to two without changing the query count. It only joins runs with identical orientation, heading and discrete state, and compares every original timed join with the replacement line within a bounded floating-point roundoff allowance. Piecewise-linear root deviation reaches its maximum at an original join; no cumulative pairwise simplification is used. Feeding contact detection keeps its original checks, then hazards and the finalized trajectory use the retained line.

The 18 empty-room fixtures combine walking/flying commands with zero wind, 0.064 m/s and the catalog fan's 0.5 m/s upper speed. All retain two knots and five queries. This is a storage improvement, not a reduction in physics work. Initial candidate-hull diagnostics formerly written by a test into `/tmp` are preserved in the results; the test no longer writes files.

Supported motion remains costly. The same upright request retains 81 knots with the fine producer; normal-aligned walking retains 73. Separating validation samples from retained knots in scratch reduces these to six or eight with a provisional 3 micrometre trajectory ceiling. The variant with a 2.25 micrometre refinement trigger measures at most 1.51 micrometres on the six request fixtures. This trigger is an experimental refinement margin, not clearance or a changed collision-query tolerance. Earlier midpoint-only variants missed a 3.303 micrometre peak and are rejected.

The faster scratch producer completes some edge-fan requests but still exhausts the unchanged query budget from the apple centre and maximum neural commands. Departure intervals inherit support state until their endpoint, so their large upper-support differences are not valid supported-path accuracy evidence. These failures remain open. No supported-producer threshold or seed change is adopted by this commit. Native and candidate timings differ substantially and are fixture-specific single native runs, not brain/WASM or whole-game measurements.

[Raw results](results.json) include every bounded comparison, including failures. Scratch sources remain in `/tmp/fly-rotation-probe` and `/tmp/fly-support-probes-combined.rs`; `/tmp/fly-supported-mid-guard-full.rs` preserves the unadopted producer. The 128 MiB cumulative archive quota still needs measured campaign contact duty; two ordinary knots do not make sustained 73-knot contact affordable.

## Full fan completion

The subsequent practical producer removes duplicate selected-food static queries after a full-hull support query at the same sample. Neighboring food remains checked, including closed containment. Balanced refinement reuses midpoint results, and coarse validation samples become retained knots only when the sampled error requires splitting. Collision classification precision remains unchanged; the provisional movement refinement trigger is 1.5 micrometres against a 3 micrometre ceiling. No root is raised to create clearance.

[Final fan results](fan-results.json) complete all twelve native/candidate fixtures, including the catalog fan speed and maximum neural motor request. Candidate centre-fan motion uses 278 queries and 113 knots, about 17 ms in this single native measurement; the full native hull costs about 115 ms there. Dense independent samples remain empirical evidence, not a continuous guarantee. High sustained contact duty can still exceed the archive or playback performance budget, and actual close-view verification remains necessary. The lifecycle and neighbor regressions remain active. Departure marks the outgoing interval as non-grounded immediately, so feeding does not persist until the end of a horizontal departure segment.
