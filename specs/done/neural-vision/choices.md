# Choices ledger

## Sound — medium confidence

- **Use optic-lobe columns as a modeled direction, not measured retinal angles.** When light arrives from one of the sampled directions, each included cell receives a weighted share based on its source column coordinate. The source data identifies cells and columns but does not supply a world-angle conversion, so the model mirrors a preferred-angle range across the two sides and uses overlapping cosine weights. This fills the task's unspecified registration rule. Future changes inherit a reproducible spatial approximation and must not describe it as measured receptive fields.

- **Confirm neural propagation separately from useful movement.** The initial plan demanded significant turning before accepting neural vision. That conflated two user objectives: a circuit can respond to light without producing a useful action. After the bounded motor experiments failed, a new protocol chose the smaller Tm2 population by size and tested all declared neural contrasts on untouched seeds. This corrected the scope before further experiments; it permits a neural result while leaving the gameplay requirement unresolved.

- **Keep brightness current positive, graded and bounded.** A brighter sample produces a stronger modeled current up to the existing gain ceiling. The task required intensity information but did not prescribe a physiological transfer function; compression makes large brightness values finite without turning them into binary detections. This is a model convention, not an assertion about ON/OFF physiology, and it constrains later tuning and interpretation.

## Sound — high confidence

- **Keep one map in the existing manifest.** A browser needs only the prepared graph artifact, not annotations or a second sensory-map service. The offline exporter writes the chosen map and its source identities into the manifest, and the existing attempt identity includes that manifest. This fills the unspecified publication boundary, preserves extraction provenance and prevents different visual mappings from masquerading as the same attempt configuration.

- **Require a downstream route for each input cell.** One connected neighbor must not make an otherwise disconnected population look meaningful. The audit checks each included cell against retained visual-relay and movement-readout paths while excluding direct movement targets. The task did not define a connectivity threshold. This makes the input population interpretable without pretending that a path guarantees activity or behavior.

- **Allow numerical rounding at the current bound.** A valid generated weight row can add to slightly more than one in binary arithmetic. The loader permits only a tiny rounding tolerance and the adapter caps the resulting current at its configured gain. The mathematical protocol left machine precision implicit; this keeps valid maps usable without allowing a meaningful dose increase.

- **Freeze the full endpoint population and correct every comparison.** Testing many neurons makes it easy to find an impressive-looking response by chance. The confirmation includes every declared downstream observation cell in a single multiple-comparison correction and saves the exact population before running. It also records scientific failures rather than overwriting them. This fills the unspecified statistical and evidence-storage contract and prevents later reviewers from mistaking a selected exploratory cell for confirmation.

- **Use a disconnected sham as a narrow machinery check.** The control silences the same number of unrelated cells with no outgoing edges, so it should leave the observed downstream activity unchanged. The task requested causal silencing but did not define this additional control. It checks that the silencing mechanism itself is not introducing the effect; it cannot support broader specificity claims about connected neurons.

- **Extend the existing workload benchmark.** Supplying a level and tuning file lets the same active-work benchmark compare vision on and off in the actual house. The old default remains available, and stopped flies cannot count as active neural work. This fills the choice of performance harness without creating a second timing implementation or a gameplay setting.
