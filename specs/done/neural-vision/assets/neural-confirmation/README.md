# Neural confirmation evidence

The [independent analysis](analysis.json) passes the preregistered neural contract: every fixed voltage contrast survives the simultaneous correction, and every optical, graded-current, input-silencing and sham check passes. This establishes input-dependent propagation through the simulated graph under this assay. The [failed motor pilot](../experiments-overlap/pilot-summary.json) remains failed; reliable turning, attraction, avoidance and a usable lighting puzzle do not follow from the neural result.

The [freeze](freeze.json) was committed before any held-out execution. It names the complete input, downstream and sham populations by index and body ID, the conditions and seeds, and every source identity. The [run marker](run-started.json) binds the single execution to those exact freeze bytes. The [raw report](neural-confirm-Tm2-3.json) retains all seed-level measurements; seeds, rather than repeated ticks, are the independent units. The analysis corrects across every cell in the entire frozen population and every preregistered contrast, without choosing a neuron from its observed effect.

The endpoint population consists of retained path witnesses, not one anatomical cell class or a uniquely established intervening route. Opposing directional distinctions and intensity responses do not establish complete eight-way behavioral decoding. Input silencing removes the light-dependent neural trajectory while allowing spontaneous dynamics. The zero-outgoing sham verifies that the silencing procedure preserves the other cells; it does not establish specificity against arbitrary connected-neuron ablation. Trajectory hashes cover every neuron's voltage, spike and refractory state at every measured tick.

Exact [probe](neural_vision_probe.rs), [map](tested-map.json), [assembled manifest](tested-manifest.json) and [analyzer](analyze_neural_vision.py) snapshots accompany the measurements. Their hashes match the freeze and analysis identities. The assembled manifest was reconstructed from the original committed base and tested map and verified against the frozen manifest hash. The graph binary itself remains the repository's unchanged, hash-identified artifact. The analyzer checks the external freeze bytes against the report before evaluating any gate and writes a fresh output file; reproductions should preserve this original evidence.

The probe's three focused tests and independent code review passed before freezing. The complete held-out panel ran once, followed by one analyzer invocation; both exited successfully. All four existing motor outputs are retained descriptively, and no neural, body or motor-decoding parameter changed for this confirmation.
