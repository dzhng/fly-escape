# Recorded eye panels

The selected fly’s paired eyes belong to the same archived tick as its neural readout. Playback uses the preceding discrete tick at a fractional cursor; spectator camera changes cannot change historical inputs. Empty input is explicit, while a recorded black sample remains a real canvas. The panels describe model color inputs without claiming subjective perception.

The archive owns sample bytes and presence. React receives the archive and small selection metadata; the canvas reads only the selected sample in a layout effect. This avoids copying every fly’s retinal arrays into React’s development performance annotations. Projection and published identities remain renderer-owned. Scene and eye-profile agreement is checked before rendering stored bytes.

[The browser fixture](../../../../tests/browser/fly-eyes.mjs) uses actual native/WASM records and the production playback UI with a finite transport fixture. Its controlled RGB patterns make every fly, eye and tick distinguishable; they are not images captured from the depicted house. The exact-pixel checks, black input, seeking, retry and camera invariance results live in [report.json](report.json). A separate component test checks missing input and scene/layout mismatch. Full campaign production and optical proof are separate integration gates.

The [earlier neural-view screenshot](baseline/vision-details.png) is retained as context from `specs/done/neural-vision/assets/browser/vision-details.png`. Its world, data, viewport and tick differ, so whole-image pixel differences would not measure UI correctness. The visual target is legible paired labels and samples above the brain, retained neural context, and no clipping or overflow at both reviewed widths. The integrating task’s unprimed reviewer accepted eye-pair legibility and layout at full size and enlarged: complete mosaics, readable labels, clean wrapping, no overlap or horizontal clipping. A separate scroll check confirms the entire brain caption and final trace are accessible at both widths; bottom captures retain that evidence.
