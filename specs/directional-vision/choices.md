# Choices

## Sound

### Treat furniture footprints as opaque at every fly height — medium confidence

A fly behind a low table may be treated as unable to see a lamp even while flying above it. This uses the environment's existing conservative geometry and keeps sensing independent of rendered artwork. Full height-aware optics would add a separate geometry contract before a useful visual response is established. The limitation remains explicit; a future height model must change sensing and its tests together.

### Represent darkness as missing modeled brightness — medium confidence

The display needs to distinguish a dark direction from a direction whose lamp is blocked. Each recorded direction therefore includes both received light and the contribution removed by walls, furniture or the local shade region. This is simulation telemetry, not a claim that flies can measure invisible lamps. Only received brightness drives the current visual adapter.

### Limit extreme light values — high confidence

Accepted source rates can be much larger than authored gameplay lights. Brightness and removed-light values saturate at one million modeled units so a finite input cannot overflow the replay. This ceiling is numerical protection, not a biological response range; circuit gain is a separate concern.

### Keep eight directions and the existing circuit groups — high confidence

Eight bins preserve which side a light is on without a rendered camera for every fly. This pass changes the detector and its recorded inputs. The existing bilateral circuit groups remain until the MaleCNS investigation chooses and tests their mapping. No new retinal correspondence is implied by the bin count.
