# Neutral window preparation

The native shape inherits the diagnostic window's 1.4 × 1.1 × 0.08 m envelope.
Two panes, rebated sash frames and an asymmetric handle provide a closed household
window. The [asset contract](../../../../../../assets/house/window/README.md)
owns orientation, placement and integration limits.

Blender MCP ran the durable source using the shared export and neutral staging
helpers. Author-time checks establish manifold edges and positive volume per
part; the shared exporter verifies native bounds after import. The GLB has one
static scene, twenty meshes, 1,840 triangles and one neutral material, with no
textures, cameras or lights. Export statistics, exact asset/capture hashes and
roundtrip measurements are stored alongside this review. These checks do not
establish an installed physical window or runtime resource disposal.

Root inspected the full views. An independent reviewer inspected all three full
frames before their detail crops, initially without source or prior-image context.
Its possible rear-bottom slit prompted source inspection: the initial sash
clearance was unbacked. Backing rebates closed that gap; a coplanar centre-post
intersection discovered by root was then removed by giving the post the outer
frame's depth. The final contextual follow-up inspected all six captures and found
no remaining visible joinery blocker: the bottom slit and centre-post artifact
are gone, with coherent front reveals and handle attachment. Confidence is
medium-high; the dark rear view limits fine-detail judgment.

All rejected captures remain in the neighboring `window-rejected`,
`window-reveal-rejected` and `window-rebate-rejected` folders. The initial staging
showed the distant ground boundary; the final stage uses a larger ground plane,
so that first version is not a pure geometry comparison. This is a new asset,
not a production-route visual change. Material/glass optics, wall installation,
browser replacement/disposal and room composition remain open.

Review retained one local shape source and shared export/staging ownership. No
runtime registry, renderer or collision code changed. Python syntax and static
GLB checks pass. Independent Codex CLI review remains unavailable because the
