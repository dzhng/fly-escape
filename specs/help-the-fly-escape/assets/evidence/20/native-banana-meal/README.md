Both use the same authored banana, seed, graph, sensory settings and initial states; only reserve replenishment is disabled in the control. Complete decoded frames and inputs are in `browser.json.gz`; `summary.json` contains per-fly results and build identity.

This is an intentionally selected meal opportunity. A native banana replaces the lifecycle probe's flat patch and sits on the observed landing route. The probe uses compressed energy costs, wind and a fixed starting pose; these are not campaign defaults. No neural gains, graph weights, fruit size or steering were changed. Food placement changes sensory inputs relative to the old flat fixture; equality is asserted between the two banana arms. This proves a physical meal and its reserve benefit, not attraction or campaign solvability.
