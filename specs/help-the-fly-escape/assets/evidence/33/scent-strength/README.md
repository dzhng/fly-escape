# Banana emission and concentration encoding

Twelve completed attempts: two paired seeds, sixteen flies, ten simulated minutes, no fan. All use the same production graph, house, native movement and original doorway-only suction. The newer room pull is excluded. The3× condition adds only extra co-located banana emission; fixed household sources stay unchanged.

| Encoding | Added banana | Final-room arrivals by seed | Escapes by seed |
| --- | --- | --- | --- |
| Binary | None | 4 / 5 | 3 / 2 |
| Binary | Normal | 6 / 7 | 2 / 1 |
| Binary | 3× emission | 7 / 9 | 4 / 5 |
| Concentration | None | 3 / 8 | 0 / 3 |
| Concentration | Normal | 6 / 7 | 2 / 4 |
| Concentration | 3× emission | 8 / 10 | 6 / 5 |

Within each encoding, higher banana emission improved arrivals and escapes in both seeds. This supports emission as a useful lever; it is a small exploratory sample, not a player success estimate or accepted level balance. Clustering ordinary objects is a separate placement question: five distributed bananas are not equivalent to one stronger source.

The scratch candidate retains the binary detector and side selection but scales detected current by c/(c+0.55), capped by the existing gain. It changes attractive AND repellent pathways and reduces every finite detected current relative to the fixed binary maximum. Therefore cross-encoding outcomes do not isolate concentration sensitivity from reduced overall drive. The curve is a modeling assumption, not validated receptor physiology. Its scale came from uniform settled-field samples, not the fly's experienced detected concentrations.

An independent read-only review verified actual sixteen-fly attempts, unchanged dynamics/suction, the banana-only emission treatment and pre-motion sample timing. Measurement limitations: the stored arrival median is the upper-middle observation and excludes non-arrivers; current is maximum excitatory adapter current, not total neuronal input; terminal flies stop contributing samples. Current and vicinity exposure depend on each realized trajectory. The agent's scratch summarizer hardcoded partial denominators; it is excluded. This report uses only complete arms with32 flies per table condition and direct raw counts. Do not infer mediation from current averages.
