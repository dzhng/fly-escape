# One fan with and without banana

This comparison tests whether the banana contributes when one fan assists within the exit room. Both conditions use the same browser-placed fan coordinates and map-owned heading, same fixed household objects, short-range suction, production graph and three seeds. Only the added banana differs. Each attempt runs20flies for ten simulated minutes.

| Condition | Escapes by paired seed | Exit-room visitors |
| --- | --- | --- |
| Fan alone | 2,7,3 | 6,10,6 |
| Fan and banana | 3,2,7 | 7,9,10 |

Both conditions average four escapes. More exit-room arrivals in the combined condition do not establish better escape performance. This arrangement supplies no aggregate banana benefit in this small tuning sample. It does not contradict the isolated nearby scent-direction effect, and the single fan must not be credited as evidence of neural attraction.

The actual browser combination finishes with three escapes, matching the first native seed. Its replay and coordinates are banked. Performance under concurrent native computation is not a release gate result. The earlier empty-house comparison remains the control for added-object usefulness; it averaged14/3 escapes.

Level1 star thresholds are provisionally1,4,8 after these playtests: a few escapes should receive intermediate feedback, with the third star above the outcomes in these tuning samples. This is not proof of the requested roughly10% player attainment. Level2 and held-out balance remain open.
