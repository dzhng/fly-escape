# Portable banana peel detail

The graded tile is a bounded material improvement, not completion of close-material realism or slice 22. Fresh visual review ranked it above the full-peel 2K bake and the original plain skin. Brown marks still look somewhat airbrushed, similar diagonal groups suggest repetition, and saturated yellow lacks natural variation at the closest camera. Whole-fruit identity improves; the inspected angles show no visible seam or loss of terminal coloration. Fly and accepted yellow marker remain readable.

The source author owns geometry and broad vertex color. Its shared skin helper authors a deterministic periodic color image offline using Blender's bundled NumPy. Standard glTF UV repetition and vertex-color multiplication carry the result; there is no runtime procedural material, new dependency, or imported-asset patch path. One 1024-square image costs approximately 5.33 MiB as RGBA with mipmaps and belongs to the shared native material. Repeated texture detail trades unique markings for fly-scale density at bounded memory. Geometry, native envelope, contact, physics, camera and lights stay unchanged.

## Choices audit

- **Shared repeated image — sound, medium confidence.** When a camera gets close to a fly, a full-peel image spreads too few pixels over its immediate surroundings. A small repeating image supplies more detail while existing vertex color retains the broad yellow and brown ends. A unique high-resolution atlas would avoid repeated clusters but cost more memory. The task left texture layout unspecified; this choice is reversible in the offline author and constrains only material appearance.
- **Bounded improvement with realism open — sound, medium confidence.** The final comparison improves recognition and close detail over the shipped plain skin, but does not make the banana photorealistic. Shipping it improves the current view while retaining the failed candidates and explicit remaining gate. Calling the whole slice complete would hide those limits.
- **Exact native surface retained — sound, high confidence.** A fly following the banana must touch the same surface after a visual change. UV and color seams may duplicate exported vertices, so the shared canonical contact bake is compared exactly, including triangle order, rather than merely checking bounds. No new collision proxy or food area is introduced.

The shared native thumbnail renderer regenerated the banana image. Actual second-house tray captures retain the 48 px object picture and readable name. The before thumbnail was supplied only for image requests; an initial scratch interception incorrectly returned PNG for Vite’s JavaScript image-import module and was corrected without app changes. Final setup visibly renders the house and objects.
