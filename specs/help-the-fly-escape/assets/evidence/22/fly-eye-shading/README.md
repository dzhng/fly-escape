# Smooth eye shading

Fresh independent review accepts this candidate as a bounded improvement: the baseline's broad polygon bands and patchy square highlights read as coarse mesh facets, not fine compound-eye structure. Smooth normals remove those artifacts while preserving the red eye separation, head gap, silhouette and selected-fly readability. The eyes still look like glossy red beads and have no fine compound-eye texture. Eye realism remains open; this is not a fly redesign or completion of slice 22.

## Choices audit

- **Smooth the existing facets — sound, high confidence.** A close camera made each coarse triangular face produce a conspicuous highlight patch. Sharing smooth normals makes light change gradually across the same triangles. Replacing the primitive or adding fine eye geometry would alter a different variable and potentially the contact envelope. Geometry stays fixed; the lack of true compound-eye texture stays explicit.
- **Refresh provenance without rebaking physics — sound, high confidence.** Changing shading changes the asset's byte hash even though every physical triangle and animation is identical. Updating only source identity keeps the hull associated with its current render asset without introducing a different convex solver output or vertex order. Exact non-identity comparisons protect that boundary.
- **Retain measured exporter drift — sound, medium confidence.** Re-running the existing source changes tiny antenna-tip normals and cyclic triangle ordering. Importing the old asset to patch those values would create a second authoring owner. The candidate instead keeps the reproducible source path and reports that small nonphysical drift; geometry, weights and animation remain exact.
