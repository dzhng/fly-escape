# Neural browser checkpoint

The actual graph runs in a Rust/WASM Worker at `/lab/brain`, presented by `apps/web` and `packages/game-renderer`. It is a 3D observation chamber, not the final game camera or art. No goal-directed steering, food, scoring or buffered swarm is claimed here.

The Rust port passes the committed Python injected-noise fixtures, including all intermediate currents, refractory order, strict threshold, clamping and ground/flight motor readouts. Independent per-fly PRNG streams are deterministic; the named stream algorithm is `splitmix64-box-muller-v1`. A strict-threshold mutation made parity fail before restoring the implementation. Graph decoding checks hash/shape/indices before constructing a brain.

The maintained wasm-bindgen Worker example was downloaded from its official source, built separately under `/tmp`, and exercised in Chrome: 24 produced even and 25 odd through the Worker. The example's legacy `no-modules` packaging was a reproduction input, not retained application architecture. The production client uses a module Worker and generated WASM. Its reproduction source URL is https://wasm-bindgen.github.io/wasm-bindgen/examples/wasm-in-web-worker.html; that page's old browser-compatibility sentence was not taken as a current limitation.

Browser verification uses `tests/browser/brain.mjs`; run it against an active dev server, or set `BRAIN_URL` to the production preview server. It verifies actual neuron/edge counts, measured neural movement, same-seed frame equality, edited-next-seed sample identity, a paired input comparison at the same tick, responsive pause, visible failed download, successful explicit retry and rejection of a partial manifest. [browser.json](browser.json) contains the production browser version, timing/memory observations and actual samples. This is a one-fly result; sustained 20-fly buffering is still slice 05's gate. A Playwright click timing is a smoke responsiveness observation, not the final complete-game latency benchmark.

Native release observation from the core agent: 671 active neural ticks/s across 200 ticks, graph load 29 ms, graph arrays 9,864,584 bytes and one brain's arrays 3,220,000 bytes. Those byte counts exclude metadata, allocator overhead and graphics. Browser evidence separately records allocated WASM linear memory; that is not whole-tab memory.

Independent code review confirmed neural parity and reset generations. Findings fixed: injection initially compared different ticks, rejected fetches stayed cached, and the chamber assumed missing group IDs. Final client retries failed fetches only on an explicit reset and rejects missing required chamber groups before ready. Normal rendering consumes core poses and chamber dimensions. The chamber mesh builder will become the general exported-geometry consumer in slice 03; no second collision owner survives that change.

Visual target for this checkpoint: read real measurements clearly, associate each label with its value and show the 3D neural subject. Camera polish, final fly assets and multi-card density belong to later slices. Compared with the mock's combined illustrative activity, the lab's separate voltage/firing columns provide the required measured distinction; the multi-fly mock remains the target for slice 13, not an exact pixel baseline for this single-fly probe. Single-shot telemetry under `visual-metrics/` locates the intentionally sparse room and white panel; their low entropy does not indicate missing subject. Row/value contrast and label separation were judged directly in crops.

The unprimed visual review found ambiguous numeric headings, faint percentages and an empty-looking first trace. Separate headings, equal-sized firing values and a labeled range/initial point fixed those issues. A final fresh review found no actionable static defects in default, card, enlarged card and explanation captures. The scrolled explanation intentionally shows lower content; the browser test verifies scrolling back to the top. Animation and the final close-follow camera are not certified by these still shots.
