# Completed placement and gain hypotheses

Fourteen completed native attempts, 20 flies and 3000 ticks each, preserved in `raw.json.gz` with exact placements, level/tuning/build hashes and per-fly aggregates. These are small tuning pilots, not campaign acceptance. The second house uses its accepted doubled movement pace. The ordinary second-house harness is banked in `../second-house-route/`; the gain variant and first-house harness are included here. No production setting or threshold changed.

| House / placement | Seeds | Escapes |
| --- | --- | --- |
| First / aligned fan plus rear vinegar | 104,106 | 12,8 |
| First / off-axis fan plus front vinegar | 104,106 | 5,4 |
| Second / study food, no editable fan | 110,111 | 0,3 |
| Second / corner fan plus doorway-front vinegars | 110,111 | 1,5 |
| Second / gain three, empty | 110,111 | 4,3 |
| Second / gain three, corner fan | 110,111 | 1,5 |
| Second / gain three, corner fan plus rear vinegars | 110,111 | 4,6 |

The first-house candidate beats its deliberately poor setup by seven and four escapes, but the existing aligned fan alone scores 13,13. Adding vinegar therefore hurts these two fan trials; do not claim this is a better reference merely because it contains more objects.

The food-only second-house setup is worse than the rear-vinegar candidate by four and three escapes. Removing the corridor fan from the previously tested study-food setup lowers escapes by two in each seed. Zero close approaches to a fan does not establish zero wind influence: proximity is not downstream exposure.

Moving both vinegars to doorway approaches gives the same escape counts as the corner fan alone; the rear-vinegar setup adds three and one. This is a placement hypothesis, not a robust poor-placement gate.

Increasing odor gain from two to three produces exactly the same per-fly aggregates and outcome counts in all six matched cells despite a changed tuning hash. The earlier cold-odor gain sweep already found saturation in this range. Keep gain two and investigate encoding/readout instead of repeating gain sweeps. Concurrent native wall times are not performance evidence.
