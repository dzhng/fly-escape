# Optional geometry input: deferred

A bounded Claude spike tested one three-ray proximity encoding into the existing
motor-excluded vision groups. Ten paired six-fly fixtures showed no clear benefit:
escapes 11 vs 13, near-blocking-footprint fraction 0.678 vs 0.733 (higher in all pairs).
No production changes were adopted.

The reported “contact rate” is a planar proximity proxy, **not a count of actual
3D collision events**. The scratch rays use fixed height rather than body height;
therefore this does not establish how accurate 3D visual avoidance would behave.
Root checked the fixture's `contains_body` metric and saved the raw results and
patch. The agent report's broad “rays work” claim should be read with those limits.
The result supports deferring this encoding, not ruling out neural vision.
