# Isolate the other objects' contribution

The calibration CLI compares the reference arrangement with the identical fan placement alone when `--fan-only-control` is requested. This replaces the obsolete comparison that removed fans, which measured fan dependence rather than whether other objects add value. The comparison requires exactly one reference fan and retains its full placement identity. Fixed environmental objects remain identical in both arms.

Its recorded control retained precisely the reference fan and removed the editable apple. A reference with no fan was rejected before simulation. The short probe never reports campaign acceptance. Focused acceptance tests reject incomplete/unfrozen/diagnostic sets, missing controls and insufficient paired benefit; topology tests continue to exercise both authored houses.

This verifies comparison wiring only. Full campaign evidence still needs frozen content and complete seed sets. The optional comparison uses the existing four-escape paired-benefit planner bar; it is not a new claim about observed gameplay or player star percentages.
