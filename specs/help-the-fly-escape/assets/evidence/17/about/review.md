# About and static-use preparation

The app composition links to a root-query About page. This works on the documented Python static server without an SPA fallback and does not alter setup/playback component files or camera layout. The footer appears after the game content; its link is keyboard reachable. The page links back to the game and uses semantic headings, sections, underlined links and visible focus outlines.

Data attribution was checked against https://male-cns.janelia.org/download/ on 2026-09-06 UTC. That official page identifies MaleCNS v1.0, credits FlyEM/HHMI Janelia, Cambridge, MRC LMB and Google Research, and links to https://creativecommons.org/licenses/by/4.0/. The page links the bundled graph manifest for exact source/hash/extraction provenance and states the graph is selected and transformed. It distinguishes real connectivity from simplified LIF state, sensory mapping, movement, feeding and energy models. The LIF reference is https://neuronaldynamics.epfl.ch/online/Ch1.S3.html. Blender project artwork is described without assigning a code/art license.

Typecheck and production build passed. A browser test used the actual static distribution served by Python at origin root: keyboard activation of About, source/license content, bundled real manifest HTTP 200, no mobile horizontal overflow, and return to setup passed with zero page errors. Desktop and narrow-screen full captures are retained. Fresh independent house-agent review inspected both full captures and found no blocking layout/readability issue: headings, paragraph spacing and underlined links are clear; the narrow title wraps cleanly and no content clips. Keyboard behavior and semantics are supported separately by the browser test/source, not inferred from screenshots. No Preview was opened; this preparation does not close release or platform/performance gates.

Merged production build passes the same keyboard navigation, manifest, mobile-width and return checks on a temporary plain Python HTTP server at the origin root.
