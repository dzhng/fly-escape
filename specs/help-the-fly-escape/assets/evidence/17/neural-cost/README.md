# Neural production cost

The [named WASM diagnosis](diagnosis.md) localizes the slow timed-round startup to neural work. Raw profiles and the production comparison are preserved alongside it; the profile script names its scratch source/build paths. This is Node/V8 evidence without Worker scheduling or rendering, over the first500ticks. The browser timing failure is recorded in [timed integration](../timed-rounds/README.md).

Root accepted the dominant-neural attribution and rejected the report's claim that a changed noise stream is required before further substantial optimization. The existing incoming graph rows have sorted source indices; a source-oriented runtime graph can skip inactive sources while preserving each target's summation order. That alternative is under independent implementation and equivalence testing. No noise algorithm, random stream or neural parameters change in this pass.

The proposed shared sine/cosine calculation is a separate measured possibility, not implemented here. Its reported corpus and microbenchmarks are diagnostic, not proof of equivalence on every supported native/browser platform. The report's claim that build identities would remain valid is also too broad: simulation source changes update this project's build identity even when neural values remain identical.

The native sample independently found most self-time in `Brain::advance`; its three-second sample is not a full-round profile. The exact full-work upper bound is798715edges ×20flies ×3000ticks =47922900000edge inspections for the old loop. Terminal flies already skip neural work, so this is an upper bound, not a measured count for attempts with escapes.
