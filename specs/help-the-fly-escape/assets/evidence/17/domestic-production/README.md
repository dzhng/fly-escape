# Domestic-house production baseline

Ten full twenty-real-brain first-house attempts played at 1× from the built static distribution in Chrome 152.0.7977.77, at 1440×1000. Each completed through the result and retry; no seek-to-end shortcut. The source includes timed wall sliding and open exit assets. Later content/tool additions require affected integration checks before release acceptance.

- Initial playback wait: 974–1162 ms; zero buffer underruns in every run.
- Frame p95: 17 ms each run. Isolated maximum intervals: 133–200 ms; this is not a claim that every frame meets budget.
- Escapes across random swarms: 15,15,11,13,18,16,15,14,17,14. This performance sample is not the frozen paired campaign evaluation.
- After every retry: one live Worker, one canvas, one document, 118 DOM nodes and 195 listeners. Collected main heap ranges 14.3–17.8 MiB, ends 17.0 MiB and drops after run six; no monotonic retained-object count growth observed.
- No browser errors. All HTTP requests were local static GETs; embedded GLB texture requests used same-origin blob URLs. An initial request assertion rejected blob URLs, then the recorded request list verified their local ownership. No new simulation run was needed to correct that inspection rule.

The compressed raw report includes all requests, body/build identities, memory and frame samples. Combined GPU memory, measured input latency, cancellation/hidden-tab checks and Firefox/Safari coverage remain final-release work. This closes neither those gates nor final campaign/photorealistic-art acceptance.
