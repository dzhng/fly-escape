# Physical-scale fixture

This diagnostic composition establishes scale without acting as a campaign level. [scale.json](scale.json) owns its units and dimensions. Its visual proxies do not grant food, support or collision roles.

[author.py](author.py) runs in Blender and writes an isolated scene and export. The fixture's above-floor content intentionally exceeds ordinary floor-kit bounds, so only the labeled proportions workbench composes it. Production loaders remain strict; this diagnostic is not a modular house kit.

The workbench combines native fly dimensions with recorded poses. Display enlargement at wide zoom changes presentation only. [Physical adoption evidence](../../specs/done/help-the-fly-escape/assets/evidence/25/adoption/README.md) records the relationship to simulation scale.

The curved-contact fixture is generated by the [core query example](../../crates/sim/examples/contact_pose_fixture.rs). The browser consumes those poses rather than creating an independent support calculation. Fixed attachment inspection is geometry evidence, not a neural attempt.
