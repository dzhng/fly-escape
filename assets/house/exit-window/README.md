# Open French window

The floor-centred origin sits on the wall plane. The fixed ivory frame leaves a 0.9 m wide, 2.05 m high passage, without a raised threshold. Both glazed casements swing 110 degrees toward local -Z, outside the clear crossing corridor. Quarter-turn 1 faces outward toward -X; quarter-turn 3 faces toward +X.

The native Blender scene and GLB own the materials and geometry. `author.py` regenerates both assets and `envelope.json`; the asymmetric envelope preserves the wall-plane origin through export validation and rendering. This is presentation attached to an existing core exit gap, not a new collision owner.
